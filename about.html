Delivery Operations
Platform

A full order-to-delivery backend system built in plain Java, running live in production. No framework. No shortcuts. A real business depending on it daily.

WhatsApp Ordering System

Two-track ordering via WhatsApp Business API where customers order directly through WhatsApp, automated callback handler with South African phone number validation. No app download required.

GPS Location System

Customer shares location once via WhatsApp and then GPS coordinates captured via webhook, saved to Google Sheets, rendered as a pinpoint on a live delivery map showing exact house and order details for every delivery run.

Driver PWA

Progressive web app running on Android and iOS via private-key-gated link. Auto-loads paid and cash orders as colour-coded map pins, draws an optimised route, tracks delivery progress live, and handles proof-of-delivery and cash reconciliation from a phone in a moving vehicle.

Automated Broadcast System

Delivery-day broadcasts sent automatically such as "on the way," "we're outside," delivery confirmations and payment confirmations all fired from backend events via Meta webhooks. No manual messaging during a delivery run.

Google Sheets Data Layer

Sheets functions as the operational database which includes order intake, payment status and delivery status all live there, read and written to automatically by both the backend and the driver app. No manual data entry during a delivery run.

Production Deployment

Backend deployed on Railway, frontend on Vercel. A real multi-service production deployment. Not local development. A business runs on this system daily.
